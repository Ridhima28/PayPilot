# Freelance Payment Assistant

An AI-assisted invoicing and payment application for freelancers and their clients, built for the PayPal AI Hackathon.

## The idea

Freelancers enter a description of their work, and AI suggests invoice details. The freelancer reviews and approves those details before the client sees the invoice and pays through PayPal's sandbox.

## Planned features

- Extract suggested invoice details from a work description
- Flag missing information and conflicting amounts
- Calculate totals using backend code
- Let freelancers review and approve invoices
- Let clients review invoices and pay with PayPal sandbox
- Verify the payment before marking an invoice as paid

## Planned technology

- **Frontend:** Angular and TypeScript
- **Backend:** Python and FastAPI
- **AI:** Qwen hosted on Groq, using the free tier initially
- **Database:** Supabase
- **Payments:** PayPal sandbox

## Project status

Planning and development are in progress. Setup instructions will be added as the application is built.
